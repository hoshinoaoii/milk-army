# 奶家军 · 抓奶仔

🎮 **在线试玩：<https://hoshinoaoii.github.io/milk-army/>**

手机打开体验最佳（竖屏全屏）。这是一个「从一堆奶仔里抓牌配对」的小游戏。

---

## 怎么玩

奶家军们挤在一个大盆里，层层叠叠压成一堆。

- **只有没被压住的奶仔才能抓** —— 能抓的会亮着，底下还带一圈淡淡的光晕；
  被压住的会变暗，像埋在下面。
- **按下去会先弹一个圈**：金色 = 能抓，红色 ✕ = 被压住，手抬起来才真正抓走。
- 抓到的奶仔飞进下方的 **奶槽**。
- **三个一样的自动消除**，得分。

---

## 奶力条

屏幕上方那条**奶力 = 时间**。

- 开局满格，随时间一路往下掉，**掉光就失败**。
- 每消除一组，**回 1 秒**。
- 奶力分成六段，每掉过一段，会有一个奶家军探头出来给你鼓劲。
- 掉进**最后一段**时，奶力条会泛红闪烁 —— 时间不多了，抓紧。

---

## 四个道具

整局共用，关键时刻再用。

| 道具 | 作用 |
|---|---|
| 🥄 **奶勺** | 从奶槽里捞出一张，放回奶仓最上面 |
| 🔔 **奶铃** | 让奶仓里数量最多的那一类全部浮到最上面 |
| 🛡️ **奶盖** | 本关奶槽 +2 格 |
| 💥 **奶爆** | 炸掉奶槽里最多的一类，最多 3 张 |

---

## 通关条件

**把奶仓里的奶仔全部抓空就通关。**

抓空了但奶槽里还剩散牌的话，每张会扣分（散牌「酸败」了）。

奶槽先被塞满，或者奶力先掉光，都算失败。

---

## 小提示

- 先看清楚**哪些是亮的**再动手，别急着乱点。
- 奶槽快满的时候，宁可先抓「已经有两张同款」的，别开新坑。
- 奶力进最后一段了，别犹豫，该用道具就用。

---

一共 5 关，越往后奶仔越多、越杂、奶力越紧。祝你好运。
